# 剩余用量显示

一个只读的 macOS 菜单栏监控器：从本机 `~/.codex/sessions` 会话日志读取 Codex 限额快照，在顶部栏显示 5 小时和 7 天窗口的剩余用量，并在菜单中展示重置时间和当前会话 token 统计。

## 功能

- 只读取本地 Codex 会话日志，不连接 Codex app-server，不上传日志，也不需要 API Key。
- 按滑动窗口聚合 5 小时和 7 天限额，保留观测到的最高已用百分比，避免稀疏快照覆盖真实用量。
- 剩余量 ≥ 50% 显示绿色，20%—50% 显示黄色，< 20% 显示红色；颜色根据浅色/深色模式自动适配对比度。
- 点击菜单栏项目可查看剩余量、已用量、重置时间和当前会话 token。

## 构建与运行

```bash
bash build-app.sh
open CodexRemainingUsage.app
```

要求 macOS 和 Swift 编译器。构建脚本使用系统 Cocoa 框架，不安装第三方依赖。

## 数据边界

本程序只读取当前用户本机的 Codex 会话日志；它不是 OpenAI API 账单，也不会执行账户操作、修改网页或上传数据。

> 说明：本仓库沿用此前桌面版的 Swift 实现，源文件还保留任务进度窗口模块，便于与同系列程序保持一致；本仓库的定位和说明聚焦于菜单栏剩余用量显示。
